    封面制作

    按「内容 → 标题 → 风格 → 构图 → 叠字」填完，直接出封面

    1 · 这是什么内容 决定风格推荐

    先判断笔记类型。同一画面最多 2 个主色 + 1 个强调色 + 3 组装饰，风格库就是这么定的。

    2 · 封面文字 主标题 0 字

    文字怎么上到图上—

    主标题 6–14 个汉字、最多 3 行，换行即分行，一行只放一个语义块。副标题 ≤22 字，可留空。封面不写长段正文。

    检查—

    3 · 风格 自动匹配

    12 种原创风格，只定义视觉语言、不套模板。选「自动」时按内容类型推一个。

    说明—

    4 · 构图与输出

    一张封面只保留一个主构图。选 2 张时会按预设差异各出一张。

    实际输出—

    5 · 叠字样式 实时预览 · 文字由浏览器排版，逐字准确

    AI 只出没有字的底图，标题由网页排版叠上去 —— 字形一定是对的，也不会出现乱码 / 缺字。改下面的参数会立刻重绘，满意了点「导出 1080×1440 PNG」。

    为什么底图是 AI 生成的，明暗不可控。文字直接压上去经常糊在背景里 —— 加一层阴影或底衬最稳。

    使用说明

    RedBuddy 怎么用

    RedBuddy 跑在你自己电脑上，帮你做四件事：拆解爆款笔记、存本地拆解库、做封面、起标题。
    整个工具会用到两个外部服务 —— Agnes AI（负责生成图片和文案）和 红狐数据 RedFox（负责取回小红书内容）。
    这两个都用邮箱注册就能免费用：不用手机号、不用绑卡。

    ① 邮箱注册 Agnes AI↗ ② 邮箱注册红狐数据↗ ③ 密钥填进「设置」 ④ 开始用

    1 Agnes AI · 生成图片和文案 邮箱注册即可免费使用

    Agnes AI 提供大模型，负责页面里所有「要动脑」和「要出图」的活。它只需要邮箱注册，注册完就能免费使用大模型来生成图片、生成文案。

    • 到 Agnes AI 官网用邮箱注册一个账号 —— 不需要手机号，也不需要绑卡。
    • 注册后在账号里生成一个 API 密钥（一串 sk- 开头的字符）。
    • 把密钥填进 RedBuddy 左侧「设置 → Agnes 密钥」里，点保存就能用了。
    • 可以填多个密钥（比如注册了几个邮箱就填几个），配合「顺序轮换」自动分摊。
    它负责拆解报告、仿写、候选标题、封面底图 —— 也就是页面里所有写着「AI 生成」的按钮。

    2 红狐数据 RedFox · 取回小红书内容 邮箱注册送 200 积分

    红狐负责把一条小红书链接变成「能拆的内容」：标题、正文全文、配图、视频口播。它同样只需要邮箱注册，注册就送 200 积分，可以免费使用。

    • 到 RedFox 官网用邮箱注册，注册即送 200 积分，直接就能用。
    • 积分用完了也不用担心 —— 换个新邮箱再注册一个账号，就又有了 200 积分。这样一直循环，就能一直免费用下去。
    • 注册后在控制台拿到 API 密钥，填进 RedBuddy 左侧「设置 → RedFox 红狐密钥」里。
    • 可以一次填多个密钥，把「轮换策略」设成「顺序轮换」—— 一个用完了自动换下一个，不用手动切。
    提示视频笔记的文案转写也走红狐服务端，所以视频笔记会比图文多消耗一些积分。

    3 把密钥填进「设置」 只存在这台电脑的浏览器里

    • 左侧点「设置」，分别填 Agnes 密钥 和 RedFox 红狐密钥，点「保存密钥」。
    • 密钥只保存在这台电脑的浏览器里（localStorage）；只在请求时传给本机的后端服务，不会上传到任何服务器，服务端也不落盘。
    • 密钥卡片上会显示「已配 N 个 Key」。没配密钥，提取和拆解都会直接报错，让你回来填。
    • 共用电脑的话，用完记得点「清空全部密钥」。

    各功能怎么用

    爆款拆解

    把小红书的分享短链粘进去（整段分享文案也行），点「开始提取」。
    工具会取回标题、正文全文、配图、互动数据；视频笔记还会自动转写口播。
    然后一次性拆成一份报告：封面钩子、标题配方、正文结构、标签、互动引导。
    报告出来直接就能看，也可以手动「存入拆解库」。

    我的拆解库

    存下来的拆解都在这儿，只存在这台电脑的浏览器里。
    能按标题 / 作者 / 短链搜索，也能按「最近保存 / 点赞最多 / 爆款指数」排序。
    点卡片看完整报告，翻旧笔记、找选题、做对标最快。

    封面制作

    按「内容类型 → 封面文字 → 风格 → 构图与输出 → 叠字样式」填完，直接出封面。
    内置 12 种原创风格、6 套配色，12 张成品模板开箱就能用。
    封面上的中文由网页用系统字体压上去、不是 AI 画的，所以不会出现乱码错字。
    想换画面可以点「用 Agnes 生成风格样图」，也可以只重出某一张。

    标题生成

    把主题或草稿写进来，工具按小红书的方法论批量产出候选标题。
    每条都会按搜索词覆盖、人群指向、收藏动机打分，并标出合规风险。
    挑一条复制就能用；还会给 Top 5 和 A/B 测试建议。

    设置

    填两个密钥的地方，另外可以选数据源、配轮换策略。
    密钥只存在本机浏览器，服务端不持有任何密钥，也没有配置文件兜底。

    常见问题

    密钥填在哪？会不会被别人看到？
    填在左侧「设置」页。密钥只保存在这台电脑的浏览器里（localStorage）， 请求时才随请求体传给本机后端，不会上传到任何服务器，服务端也不落盘。 共用电脑请用完点「清空全部密钥」。
    拆解 / 出图失败了，从哪查？
    按顺序检查三件事：
    ① 密钥填了吗 —— 「设置」里对应卡片要显示「已配 N 个 Key」；
    ② 密钥还有效吗 —— 免费额度用完了，就换个邮箱重新注册一个账号，把新密钥填进来；
    ③ 网络通吗 —— 服务要访问 Agnes 和红狐的接口，代理 / VPN 有时会挡住，可以换个网络再试。
    笔记取不到，提示 token 失效？
    分享链接里的 token 有时效。回到小红书 App，对那条笔记重新「复制链接」再试一次。
    拆解库和封面模板会丢吗？
    它们都存在浏览器本地存储里，换浏览器、清缓存、无痕模式都会看不到。 封面样图库可以在封面页点「导出样图库」存一份 JSON，换环境后再「导入样图库」导回来。
    数据会上传到云端吗？
    不会。RedBuddy 是一个跑在本机的小服务：拆解库、密钥、封面样图都存在你的浏览器里， 服务端只做转发，不保存任何东西。所以关掉这个服务，工具就用不了 —— 这是设计如此，不是缺陷。
