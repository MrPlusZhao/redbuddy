它是什么一句话

贴一条小红书分享短链，自动取回笔记原文（标题 / 正文 / 配图 / 互动数），视频笔记再转出口播逐字稿， 然后交给 Agnes 出一份 8 节结构化拆解报告，并自动存进本机的「拆解库」。 整个过程在一台 Mac 上跑，没有登录、没有扫码、没有云端账号。

定位：给自己用的选题 / 文案复盘工具。不是批量采集器。

架构4 个文件，零第三方依赖

本地代理 server.js
HTTP 路由、Agnes 调用与 JSON 自愈解析、托管前端页。不持有任何密钥，Key 由前端随请求带上来。
内容获取 collector.cjs
短链 → 笔记原文；视频 → 服务端转写（提交 ASR 任务后轮询结果）。
数据源适配 providers.cjs
把厂商接口差异收敛成统一结构。换厂商只改一处；含短链展开、错误码翻译、页面兜底。
网络真因 neterr.cjs
把 fetch failed 还原成真因（DNS / TLS 证书 / 拒绝连接 / 超时），全站报错文案统一走它。

前端是单个自包含的 index.html，无构建步骤；配置在 config.local.json（不含密钥）。

Agnes · 邮箱注册免费用

两个账号怎么注册都只要邮箱

账号怎么用
Agnes AI邮箱注册即可，注册完就能免费使用大模型生成图片和文案
红狐数据 RedFox邮箱注册送 200 积分；用完了换个新邮箱再注册一个，可以一直用
本机运行 / 存储免费，数据不出本机
  • 密钥配多个 + 顺序轮换：注册了几个邮箱就填几个 Key，一个用完了自动换下一个。
  • 离线自检：config.local.json 里把 xhsProvider 改成 mock， 不联网跑通整条链路（改完记得改回 redfox）。
  • 明显无效的输入会被提前拦下，不会白跑一次调用。
  • 拆解库点开不重跑模型，回看报告不会重复调用。

能力边界先知道，少踩坑

  • 只有红狐一家数据源，没有备用；它挂了就只能用 mock。
  • 视频笔记拿不到配图 —— 红狐对视频只给无水印直链，图片列表为空；报告里「配图」区只对图文笔记展示。
  • 分享链接的 token 会失效，取不到就在 App 里重新复制一次链接。
  • 转写失败多是上游抽风，同一链接时好时坏、有几分钟窗口期，重试即可。
  • 密钥只在浏览器里，换浏览器 / 清缓存要重新配；服务端永远不落盘。
  • 仅供个人分析，勿批量采集或二次分发他人内容。
