# RedBuddy 使用说明

一个**在你本机跑**的小红书内容工具。不需要登录、不需要扫码、不需要把账号交给谁。

它把「看一条爆款笔记 → 拆出它为什么火 → 顺手写出你自己的标题和封面」串成一条流水线。

> 应用里也有一份同样的说明：打开网页 → 左侧菜单 **「使用说明」**。

---

## 一、装与起

### 1. 装 Node

只要 Node 18 或更高版本，**没有第三方依赖**。

- macOS：`brew install node`
- 其它：https://nodejs.org 下载 LTS 版

验证：终端里敲 `node -v`，能打印版本号就行。

### 2. 装 RedBuddy

```bash
bash scripts/install.sh          # 默认装到 ~/RedBuddy
```

### 3. 启动

```bash
bash scripts/start.sh
```

等它打印 `✅ RedBuddy 已就绪`，浏览器会自动打开 **http://127.0.0.1:8090/**。

> macOS 用户也可以直接双击应用目录里的 **「启动.command」**。
> 用完想停：`bash scripts/stop.sh`。

## 二、注册两个账号（都免费）

RedBuddy 会用到两个外部服务。**两个都只需要邮箱注册，就能免费使用**，
不用手机号、不用绑卡。

### ① Agnes AI —— 生成图片和文案

负责页面里所有「要动脑」和「要出图」的活。

1. 到 Agnes AI 官网**用邮箱注册一个账号**
2. 注册后在账号里生成一个 **API 密钥**（一串 `sk-` 开头的字符）
3. 把密钥填进 RedBuddy 左侧「**设置 → Agnes 密钥**」，点保存

它负责：**拆解报告、仿写、候选标题、封面底图** —— 也就是页面里所有写着「AI 生成」的按钮。

### ② 红狐数据 RedFox —— 取回小红书内容

负责把一条小红书链接变成「能拆的内容」：标题、正文全文、配图、视频口播。

1. 到 RedFox 官网**用邮箱注册**，注册即送 **200 积分**，直接就能用
2. **积分用完了也不用担心** —— 换个新邮箱再注册一个账号，就又有了 200 积分。
   这样一直循环，就能一直免费用下去
3. 注册后在控制台拿到 **API 密钥**，填进左侧「**设置 → RedFox 红狐密钥**」

> 视频笔记的文案转写也走红狐服务端，所以视频笔记会比图文多消耗一些积分。

### 两个都支持配多个密钥

密钥卡片里可以加多个 Key（注册了几个邮箱就填几个），
「轮换策略」选 **顺序轮换**，一个用完了自动换下一个，不用手动切。

| 密钥 | 干什么用 |
|---|---|
| **RedFox 红狐** | 取小红书内容（标题 / 正文 / 配图 / 互动数）+ 视频转写 |
| **Agnes** | 拆解报告、出封面图、出标题 |

**密钥只存在你这台电脑的浏览器里**，不上传、不写进任何配置文件、服务端也拿不到。

## 三、五个页面怎么用

### ① 爆款拆解 —— 主入口

1. 在小红书 App 里点笔记右上角 → **复制链接**（得到 `xhslink.cn/o/xxx` 这样的短链）
2. 粘进「爆款拆解」页，点开始
3. 顶部会有一条常驻进度条，走六步：
   **校验链接 → 请求数据源 → 归一化字段 → 提取口播 → Agnes 拆解 → 生成报告**
4. 跑完自动打开报告页

报告固定 8 节：`封面分析 / 标题拆解 / 正文结构 / 标签策略 / 互动率判断 / 爆款因子 / 风险点 / 需求与任务`。
前面还有一块「原始素材」，把拿到的正文、口播逐字稿、配图原样留着。

> 视频笔记会先自动转写出口播逐字稿，再进拆解。
> 没配 Agnes Key 的话，链路会停在「提取完成」并提示你去配。

### ② 我的拆解库

报告页右上角点 **「存入拆解库」** 才会入库（不点就不存）。

- 点卡片**直接渲染**，不会重新调模型
- 支持按标题 / 作者 / **短链**搜索，按时间或分数排序
- 删除是两段式：点「删除」变「确认删除」，3 秒内再点才真删
- 记录里存了当初那条**分享短链** —— 视频直链过期后靠它重新解析

### ③ 封面制作

按五步填表：**内容类型 → 封面文字 → 风格 → 构图与输出 → 叠字样式**，然后生成。

- 内置 **12 种原创风格**、6 套配色、8 种构图，**12 张成品模板开箱即用**
- 风格选择是**看图选**（样图已经内置好了，不用你重新出）
- 一张封面只保留一个主构图；选 2 张会按预设差异各出一张
- 字号、行距、文字颜色、纵向位置、对齐都能实时调，改一下预览立刻重绘

**关键设计**：AI 只画**没有字**的底图，标题由网页用真实字体压上去 ——
所以**中文字形一定是对的**，不会出现 AI 画字的乱码 / 缺笔。字号、颜色、位置随时可改，
最后导出 1080×1440 PNG。

### ④ 标题生成

填一句主题（或贴一条现成标题让它优化），出 **12 或 20 个候选**：

- 每条带**字符数**（超 20 字会被平台截断，标红）、**评分**、**风险标注**
- 覆盖至少 6 种方法（数字清单 / 反常识纠错 / 人群标签 / 搜索词卡位 …）
- **Top 5 推荐**按用途分角色，不是按分数机械排
- 给 **A/B 测试建议**，并说明每组该看哪个指标

### ⑤ 设置

两把密钥 + 存储位置说明。改完立即生效，不用重启。

## 四、一次操作会用到哪个账号

配好密钥后，涉及网络请求的操作会分别打到两个服务上：

| 操作 | 走哪个服务 |
|---|---|
| 启动、翻拆解库、改封面参数、调字号 | 只用本机，不联网 |
| 封面样图库那 12 张 | 已内置，不用重新出图 |
| 解析一条短链（取内容） | 红狐 |
| 视频笔记转写 | 红狐 |
| 出拆解报告 / 出标题 / 出一张封面图 | Agnes |

**建议**：先用一条你自己熟悉的笔记跑通全流程，确认没问题了再批量用。

## 五、三个必须知道的坑

### 1. 必须用「分享短链」

数据源是按链接取内容的：

- ✅ `https://xhslink.cn/o/xxxxx`（App 里复制链接得到的）
- ✅ 整段分享文案（会自动抠出链接）
- ⚠️ 只有 24 位笔记 ID：有时能试，取不到就回 App 重新复制链接

### 2. 密钥只在本机浏览器里

服务端不持有密钥。换浏览器、换电脑、清了缓存，**都要重新填**。

### 3. 视频直链是带时效的

工具只存「地址」，不下载视频。直链过期后播放会失败，
回「爆款拆解」用当初那条短链重新解析就行（拆解库里存了这条短链）。

## 六、不消耗额度的自检

想先确认工具本身装对了、链路通了，可以切成本机假数据跑一遍：

1. 打开应用目录里的 `config.local.json`
2. 把 `"xhsProvider"` 改成 `"mock"`
3. 重启服务，这时不联网也能跑通「贴链接 → 取到内容」这一段
4. 验证完**记得改回 `"redfox"`**

## 七、隐私与边界

- **视频和图片都不存在你本机**，只存地址；服务端边拉边转发，不落盘。
- **密钥不落盘**，只在浏览器 localStorage。
- 内容获取走第三方数据源，工具本身不做浏览器登录态采集、不绕过登录。
- 拆解结论是对**公开内容**的分析，不代表平台官方数据。
  别用它生成虚假数据、夸大收益或伪造案例。
